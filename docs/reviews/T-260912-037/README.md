# T-260912-037 · 작업장 디자인 검토

제품, 홈, 공통 내비게이션/푸터, 기록 세 종류의 목록/본문, 소개·시스템·실험실을 따뜻한 종이색과 버밀리언 포인트로 재구축했다. 제품별 CSS 그림, 21개 제품 검색/분류, 기록 검색, 실제 제목에 연결되는 본문 목차를 제공한다. 내부 참고 페이지에는 같은 토큰과 프레임을 적용했다.

제품 데이터·링크·글 원문·회사정보는 기준 커밋 `f5ed76d` 그대로다. 외부 회사/조직도/제품 서비스와 독립 법률 문서, 기존 리다이렉트는 이 디자인 변경의 대상 밖이다. 기존 사용자 체크아웃은 깨끗한 상태로 보존했다. 의존성과 배포 워크플로는 변경하지 않았다.

## 검증

- 프로덕션 빌드: 508페이지. 공유 레이아웃 적용 506페이지, 유틸리티 리다이렉트 2페이지.
- 전체 내부 링크: 7,635개, 깨진 링크 0개.
- 신규 렌더 검증: 21제품, 주요 화면 링크 553개, 본문 앵커 3,349개, 로컬 이미지/스크립트/CSS 경로 통과.
- 검색 단위 테스트: 5/5. 빈 입력, 한글 조합, 전각/영문 대소문자, 다중 검색어, HTML/정규식 문자 리터럴 처리.
- 뉴스레터 수집기 설정과 상품 링크 계측 검증 통과. 기존 뉴스레터 테스트 26/26도 통과했다.
- 실제 UI: 오픈소스 5개 → 전각 검색어 ＣＯＤＥＸ 2개 → 없는 제품 0개 → 초기화 21개. 작업일지 검색 0개 → 초기화 145개.
- 키보드: Tab으로 본문 바로가기 접근 후 본문에 포커스 이동. 더보기 메뉴 Enter 열기, Escape 닫기 및 포커스 복귀.
- 좁은 화면: 제품 320/390px, 소개/실험실/본문/참고 문서 320px. 데스크톱: 제품/홈/기록/시스템 1440px 시각 확인.
- 기준 데이터·글·public·의존성 lock·워크플로 변경 없음. 보호 마커가 있던 블록 삭제 없음.

기존 `verify:public-secrets`는 `src/lib/nl-allowlist.mjs:2`의 작업번호 주석을 `chat id numeric literal`로 오탐한다. 해당 파일과 검사기는 이번 변경에서 수정하지 않았고 기준 커밋으로 같은 실패를 재현했다. 이 검사는 통과로 처리하지 않는다.

한줄일기 개인정보 처리방침

최종 업데이트: 2026년 8월 6일

개요

한줄일기(Hanjul)는 사용자가 하루 한 줄의 일기를 남기면 짧은 답글을 보여주는 앱입니다. 서비스를 제공하기 위해 필요한 최소한의 데이터만을 처리하며, 개인 식별 정보(이름·이메일·전화번호·로그인 계정 등)는 일체 수집하지 않습니다.

2026년 8월 업데이트 — 외부 AI 서비스로 일기 텍스트를 전송하던 답글 생성 기능이 앱에서 제거됐습니다. 이제 답글은 앱 안에 내장된 문구 중에서 기기가 직접 골라 보여주며, 일기 내용은 어떤 외부 서버로도 전송되지 않습니다. 같은 업데이트로 유료 구독 판매도 중단됐습니다.

수집·처리하는 정보

한줄일기는 다음 정보를 처리합니다:

  • 사용자가 직접 입력한 일기 텍스트 — 기기 내부에만 저장되며 외부로 전송되지 않습니다.
  • 익명 기기 식별자 — 앱이 최초 실행될 때 무작위 문자열을 생성해 기기 내부에만 저장합니다. 아래 "구매 복원" 항목의 요청에만 사용되며, 개인 식별은 불가능합니다. 앱을 삭제하면 함께 사라집니다.

한줄일기 앱 자체는 이름·이메일·전화번호·연락처·사진·마이크 접근 권한을 수집하지 않으며, 회원가입·로그인 절차가 없습니다. 광고 SDK 가 처리하는 광고 식별자·대략적인 위치 등은 아래 "광고" 항목을 참고해 주세요.

데이터 흐름 (답글)

답글은 기기 안에서만 만들어집니다. 앱에 미리 담겨 있는 문구 중에서 일기의 분위기에 맞는 것을 기기가 골라 보여주며, 이 과정에서 네트워크 통신은 일어나지 않습니다. 일기 텍스트가 외부 서버·AI 서비스로 전송되는 경로는 없습니다.

과거 버전에서 외부 AI 서비스로부터 받아 기기에 저장해 둔 답글은 그대로 읽고 볼 수 있도록 보존됩니다. 이 데이터 역시 기기 안에만 있습니다.

구매 복원

사용자가 설정 화면에서 구매 복원을 직접 실행할 때에 한해, 앱이 hanjul-proxy.ssamssae.workers.dev 로 익명 기기 식별자와 사용자가 입력한 주문번호를 HTTPS 로 전송해 과거 구매 이력을 확인합니다. 일기 텍스트는 이 요청에 포함되지 않습니다. 사용자가 이 버튼을 누르지 않으면 어떤 요청도 발생하지 않습니다.

데이터 저장

사용자가 작성한 일기와 답글은 사용자 기기 로컬 저장소(Android: SharedPreferences, iOS: UserDefaults)에만 영구 보관됩니다. 한줄일기 앱 자체는 사용자별 데이터를 서버에 저장하지 않으며, 어떤 계정에도 동기화되지 않습니다. 앱을 삭제하면 기기 내부의 모든 일기·답글 데이터가 함께 삭제됩니다.

광고

한줄일기는 Google AdMob 광고 SDK(google_mobile_ads) 를 포함합니다. 광고가 게재될 때 AdMob 은 광고 식별자, 대략적인 위치, 기기 식별자, 앱 이용 상호작용 등을 수집·이용할 수 있으며, 이 처리는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트·앱에서의 데이터 이용 을 확인해 주세요.

Google Play 스토어의 "데이터 보안" 항목에도 같은 내용이 선언돼 있습니다. 이 문서와 스토어 선언이 다르면 스토어 선언이 최신입니다.

사용자가 작성한 일기 본문 자체는 광고 SDK 로 전달되지 않습니다.

제3자 제공 및 공유

한줄일기는 광고 게재를 위해 Google(AdMob) 을 이용하며, 그 밖에 아래 서비스를 이용합니다:

  • Cloudflare, Inc. — 위 "구매 복원" 요청을 받는 프록시 인프라 제공. 요청 전송 과정에서 표준 HTTP 로그(IP·요청 시각·응답 코드) 가 최대 30일간 보관될 수 있습니다. 사용자가 구매 복원을 실행하지 않으면 이 경로는 사용되지 않습니다.

위에 적은 서비스(Google·Cloudflare) 외에는 어느 제3자에게도 사용자의 데이터를 제공하거나 판매하지 않습니다. 종전 방침에 적혀 있던 OpenAI 로의 일기 텍스트 전달은 해당 기능이 앱에서 제거되면서 더 이상 발생하지 않습니다.

결제

한줄일기의 모든 기능은 무료입니다. 유료 구독 판매는 2026년 8월 업데이트로 중단됐습니다. 앱 안에서 구독을 새로 구매하는 경로는 제공되지 않습니다.

  • 광고 제거 — 광고를 없애는 1회성 인앱 구매만 제공합니다. 결제는 앱이 직접 처리하지 않고 각 앱 마켓(iOS: Apple App Store, Android: Google Play)의 인앱 결제 시스템을 통해서만 이뤄집니다. 카드 번호 등 결제 수단 정보는 해당 마켓이 관리하며, 한줄일기 앱은 사용자의 결제 정보를 수집하거나 저장하지 않습니다.
  • 앱이 전달받는 정보 — 앱은 마켓으로부터 구매의 활성화 상태만 전달받아 광고 표시 여부를 정하는 데 사용합니다. 이 상태 정보에는 이름·이메일 등 개인 식별 정보가 포함되지 않습니다.
  • 기존 구독을 갖고 계신 경우 — 확인·해지·환불 요청은 각 마켓의 구독 관리 화면에서 진행합니다. iOS 는 "설정 → Apple 계정 → 구독", Android 는 "Google Play → 프로필 → 결제 및 구독 → 구독" 경로입니다.

어린이 개인정보 보호

한줄일기는 만 13세 미만 어린이를 대상으로 하지 않습니다. 만 13세 미만 이용자의 개인정보를 의도적으로 수집하지 않으며, 어린이임이 확인되는 경우 해당 데이터를 즉시 삭제합니다.

보안

앱과 프록시 사이의 모든 통신은 HTTPS(TLS) 로 암호화됩니다. 기기 내부 저장소는 운영체제의 앱 샌드박싱으로 보호되며, 민감한 내용을 기록하는 경우 기기 자체의 잠금 기능을 활성화하는 것을 권장합니다.

사용자 권리

한줄일기는 서버에 사용자별 데이터를 보관하지 않으므로 별도의 계정 삭제 절차가 없습니다. 앱 내부에서 개별 일기 항목을 삭제하거나 앱 자체를 기기에서 삭제함으로써 모든 데이터를 완전히 제거할 수 있습니다.

정책 변경

이 개인정보 처리방침은 앱의 기능 변경이나 제3자 서비스 정책 변경에 따라 업데이트될 수 있습니다. 변경 사항이 있을 경우 이 페이지에 반영되며, 최종 업데이트 날짜가 갱신됩니다.

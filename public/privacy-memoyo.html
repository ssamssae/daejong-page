메모요 개인정보 처리방침

최종 업데이트: 2026년 7월 30일

개요

메모요(Memoyo)는 꼭 필요한 것만 남긴 심플한 다크 모드 메모 앱입니다. 회원가입·로그인·자동 서버 동기화가 없고, 이름·이메일·전화번호 같은 개인 식별 정보를 수집하지 않습니다. 다만 앱에는 Google AdMob 광고 SDK 가 포함돼 있고, 말로 검색용 모델 내려받기와 Google Drive 백업 등에서 외부와 통신합니다.

수집·처리하는 정보

메모요는 사용자가 앱에서 입력하는 정보를 다음과 같이 처리합니다:

  • 메모 본문 — 사용자가 직접 작성한 메모 텍스트.
  • 즐겨찾기 표시 — 스와이프로 고정한 메모 식별 정보.
  • 메모 정렬 순서 — 드래그로 사용자가 직접 지정한 순서.

위 항목은 사용자 기기 내부 로컬 저장소(iOS / Android 의 SharedPreferences) 에 저장되며, 메모요가 자체 서버로 자동 업로드하지 않습니다. 사용자가 Google Drive 백업을 실행하는 경우와 프리미엄 말로 검색 서버 경로가 켜진 빌드는 예외이며, 아래 "네트워크 통신" 항목에 적었습니다.

메모요가 직접 수집하지 않는 정보

아래 항목은 메모요 앱이 직접 요청하거나 수집하지 않습니다. 광고 SDK 가 처리하는 정보는 별도이며 아래 "광고" 항목을 참고해 주세요.

  • 이름·이메일·전화번호·생년월일
  • 연락처·사진·마이크·카메라 접근 권한
  • 메모 본문의 자동 서버 동기화·계정 연동

광고

메모요는 Google AdMob 광고 SDK(google_mobile_ads) 를 포함합니다. 광고가 게재될 때 AdMob 은 광고 식별자, 대략적인 위치, 기기 식별자, 앱 이용 상호작용 등을 수집·이용할 수 있으며, 이 처리는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트·앱에서의 데이터 이용 을 확인해 주세요.

Google Play 스토어의 "데이터 보안" 항목에도 같은 내용이 선언돼 있습니다. 이 문서와 스토어 선언이 다르면 스토어 선언이 최신입니다.

사용자가 작성한 메모 본문 자체는 광고 SDK 로 전달되지 않습니다.

제3자 제공 및 공유

메모요는 광고 게재를 위해 Google(AdMob) 을, 말로 검색용 모델 배포를 위해 Hugging Face 를 이용합니다. 사용자가 백업 기능을 실행하면 Google Drive 로 백업 파일이 전송됩니다. 그 밖의 제3자에게 메모 데이터를 제공하거나 판매하지 않습니다.

네트워크 통신

메모 작성·보관 기능 자체는 인터넷 없이도 동작하지만, 메모요는 아래 경우에 외부와 통신합니다. "외부 서버와 전혀 통신하지 않는다"는 표현은 정확하지 않아 바로잡습니다.

  • 광고 — 광고를 불러오기 위해 광고 SDK 가 Google 서버와 통신합니다.
  • 말로 검색용 모델 내려받기 — 기기에서 검색을 처리하기 위한 언어 모델 파일을 huggingface.co 에서 내려받습니다. 이때 메모 내용은 전송되지 않습니다.
  • Google Drive 백업 — 사용자가 백업 기능을 직접 실행할 때에 한해 사용자의 Google Drive 로 백업 파일을 올리거나 내려받습니다. 이 경우 메모 내용이 사용자 본인의 Google 계정 저장공간으로 전송됩니다.
  • 인앱 결제 — 구매·복원 시 각 앱 마켓(Apple App Store · Google Play) 과 통신합니다.
  • 프리미엄 말로 검색 — 앱에는 검색용 문장 처리를 서버에서 수행하는 경로가 함께 구현돼 있습니다. 이 경로가 켜진 빌드에서는 검색에 사용되는 메모 텍스트가 처리 서버로 전송될 수 있습니다.

기기 센서 사용

메모요는 인터랙션 보조를 위해 기기 모션 센서를 활용할 수 있으나, 센서 데이터는 모두 앱 내부에서만 처리되며 외부로 전송되거나 저장되지 않습니다.

어린이 개인정보 보호

메모요는 모든 연령대가 사용할 수 있는 앱이지만, 만 13세 미만 어린이를 대상으로 하지 않으며 어린이의 개인정보를 의도적으로 수집하지 않습니다.

사용자 권리 및 데이터 삭제

메모요는 계정을 만들지 않으므로 별도의 계정 삭제 절차가 없습니다. 앱을 기기에서 삭제하면 앱이 저장한 모든 데이터(메모 본문, 즐겨찾기, 정렬 순서) 가 함께 즉시 제거됩니다. Google Drive 에 올린 백업 파일은 사용자가 Drive 에서 직접 삭제해야 합니다. 광고 식별자 초기화는 기기 설정(iOS: 설정 → 개인정보 보호, Android: 설정 → Google → 광고) 에서 하실 수 있습니다.

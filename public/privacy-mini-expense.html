가계부 개인정보 처리방침

최종 업데이트: 2026년 11월 17일

개요

가계부(Mini Expense)는 지출을 빠르게 기록하는 심플한 가계부 앱입니다. 회원가입·로그인·서버 동기화가 없고, 이름·이메일·전화번호 같은 개인 식별 정보를 수집하지 않습니다. 다만 앱에는 Google AdMob 광고 SDK 가 포함돼 있습니다. 광고를 위해 처리되는 정보는 아래 "광고" 항목에 적었습니다.

수집·처리하는 정보

가계부 자체는 사용자가 앱에서 입력하는 정보를 서버로 보내지 않습니다. 각 항목은 다음과 같이 처리됩니다:

  • 지출 금액 — 사용자가 직접 입력한 금액.
  • 메모 — 지출에 대해 사용자가 작성한 설명 텍스트.
  • 카테고리 — 사용자가 선택한 지출 분류 정보.

위 항목은 모두 사용자 기기 내부 로컬 저장소(iOS / Android 의 SharedPreferences) 에만 저장되며, 외부 서버나 제3자에게 전송되지 않습니다. 사용자가 직접 백업을 실행했을 때만 아래 "로그인 없는 백업·복원" 항목처럼 백업 파일이 사용자가 고른 위치나 사용자 본인의 iCloud에 저장됩니다.

가계부가 직접 수집하지 않는 정보

아래 항목은 가계부 앱이 직접 요청하거나 수집하지 않습니다. 다만 광고 SDK 가 처리하는 정보는 별도이며 아래 "광고" 항목을 참고해 주세요.

  • 이름·이메일·전화번호·생년월일
  • 연락처·사진·마이크·카메라 접근 권한
  • 지출 기록의 서버 전송·계정 동기화
  • 계좌·카드 등 금융 계정 정보(앱은 금융기관에 연결되지 않습니다)

로그인 없는 백업·복원

사용자가 설정 화면에서 백업 버튼을 직접 누를 때에 한해, 앱이 지출 기록(금액·메모·카테고리·기록 시각)을 파일 하나로 묶어 저장합니다. 복원은 사용자가 고른 백업 파일을 읽어 지금 없는 기록만 더하는 방식이며, 기기에 있던 기록은 지우지 않습니다. 이 백업에는 로그인이 필요 없습니다.

  • 아이폰 — iCloud: 백업 파일을 사용자 본인의 iCloud Drive 안 "가계부" 폴더에 저장하고, 최근 백업 5개를 남깁니다. 같은 Apple 계정으로 로그인한 새 아이폰·아이패드에서 복원할 수 있습니다. 기기에서 iCloud Drive가 꺼져 있으면 이 기능을 쓸 수 없습니다.
  • 파일: 기기의 저장 창에서 사용자가 고른 위치에 백업 파일을 저장하고, 복원할 때도 사용자가 고른 파일만 읽습니다. 안드로이드는 이 방법을 쓰고, 아이폰에서는 안드로이드 폰으로 옮길 때 씁니다.
  • 개발자 접근 없음: 백업 파일은 사용자가 고른 저장 위치나 사용자 본인의 iCloud에만 저장되고, 개발자 서버로는 보내지 않습니다. 개발자는 백업 파일을 받거나 볼 수 없습니다.
  • 암호화: 백업 파일은 앱이 따로 암호화하지 않습니다. iCloud에 저장한 파일은 Apple iCloud의 보호를 따릅니다. 백업 파일을 다른 사람과 공유하지 마세요.
  • 삭제: iCloud 백업은 파일 앱의 iCloud Drive "가계부" 폴더나 기기 설정의 iCloud 저장 공간 관리에서, 파일 백업은 저장한 위치에서 직접 지울 수 있습니다.

광고

가계부은 Google AdMob 광고 SDK(google_mobile_ads) 를 포함합니다. 광고가 게재될 때 AdMob 은 광고 식별자, 대략적인 위치, 기기 식별자, 앱 이용 상호작용 등을 수집·이용할 수 있으며, 이 처리는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트·앱에서의 데이터 이용 을 확인해 주세요.

Google Play 스토어의 "데이터 보안" 항목에도 같은 내용이 선언돼 있습니다. 이 문서와 스토어 선언이 다르면 스토어 선언이 최신입니다.

사용자가 입력한 지출 금액·메모·카테고리 자체는 광고 SDK 로 전달되지 않습니다.

제3자 제공 및 공유

가계부는 광고 게재를 위해 Google(AdMob) 을 이용합니다. 아이폰에서 사용자가 iCloud 백업·복원을 실행하면 Apple(iCloud)이 사용자 본인의 iCloud Drive에 백업 파일을 저장하거나 읽어 옵니다. 그 밖의 제3자에게 사용자의 데이터를 제공하거나 판매하지 않습니다.

네트워크 통신

지출 기록 기능 자체는 인터넷 없이도 동작합니다. 다만 광고를 불러오기 위해 광고 SDK 가 Google 서버와 통신합니다. 따라서 앱이 외부와 전혀 통신하지 않는 것은 아닙니다. 아이폰에서 iCloud 백업·복원을 실행하면 Apple iCloud 와도 통신합니다.

어린이 개인정보 보호

가계부는 모든 연령대가 사용할 수 있는 앱이지만, 만 13세 미만 어린이를 대상으로 하지 않으며 어린이의 개인정보를 의도적으로 수집하지 않습니다.

사용자 권리 및 데이터 삭제

가계부는 서버에 사용자 데이터를 보관하지 않으므로 별도의 계정 삭제 절차가 없습니다. 앱을 기기에서 삭제하면 앱이 저장한 모든 데이터(지출 금액, 메모, 카테고리) 가 함께 즉시 제거됩니다. 사용자가 만든 백업 파일(iCloud·파일)은 앱을 지워도 남으며, 위 "로그인 없는 백업·복원" 항목의 방법으로 직접 지울 수 있습니다. 광고 식별자 초기화는 기기 설정(iOS: 설정 → 개인정보 보호, Android: 설정 → Google → 광고) 에서 하실 수 있습니다.

정책 변경

이 개인정보 처리방침은 앱의 기능 변경에 따라 업데이트될 수 있습니다. 변경 사항이 있을 경우 이 페이지에 반영되며, 최종 업데이트 날짜가 갱신됩니다.

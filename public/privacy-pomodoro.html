포모도로 개인정보 처리방침

최종 업데이트: 2026년 7월 30일

개요

포모도로(Pomodoro)는 25분 집중 / 5분 휴식 사이클을 가장 단순하게 굴리는 타이머 앱입니다. 개인 식별 정보(이름·이메일·전화번호·로그인 계정 등)는 수집하지 않습니다. 다만 앱에는 Google AdMob 광고 SDK 가 포함돼 있습니다. 광고를 위해 처리되는 정보는 아래 "광고" 항목에 적었습니다.

수집·처리하는 정보

포모도로가 다루는 타이머·집중 기록 데이터는 사용자 기기 내부에서만 생성·저장되며 서버로 전송되지 않습니다.

기기 내부에 저장되는 항목:

  • 오늘 완료한 포모도로 사이클 수 — 화면 표시를 위한 카운터.
  • 최근 7일 간의 일별 집중 세션 수 — 주간 통계 그래프 표시를 위해 기기 로컬에 저장.
  • 타이머 상태 — 앱을 다시 실행했을 때 이어가기 위해 잠시 보관. 앱 종료 시 초기화될 수 있음.

포모도로 앱 자체는 이름·이메일·전화번호·연락처·사진·마이크·카메라 정보를 수집하지 않으며, 회원가입·로그인 절차가 없습니다. 광고 SDK 가 처리하는 정보는 아래 "광고" 항목을 참고해 주세요.

데이터 저장

위 정보는 사용자 기기 로컬 저장소(Android: SharedPreferences, iOS: UserDefaults)에만 보관됩니다. 포모도로 앱은 사용자별 데이터를 서버에 저장하지 않으며, 어떤 계정에도 동기화되지 않습니다. 앱을 삭제하면 기기 내부의 모든 포모도로 관련 데이터가 함께 삭제됩니다.

네트워크 통신

타이머 기능 자체는 인터넷 없이도 동작합니다. 다만 광고를 불러오기 위해 광고 SDK 가 Google 서버와 통신합니다. 따라서 앱이 외부와 전혀 통신하지 않는 것은 아닙니다.

광고

포모도로은 Google AdMob 광고 SDK(google_mobile_ads) 를 포함합니다. 광고가 게재될 때 AdMob 은 광고 식별자, 대략적인 위치, 기기 식별자, 앱 이용 상호작용 등을 수집·이용할 수 있으며, 이 처리는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트·앱에서의 데이터 이용 을 확인해 주세요.

Google Play 스토어의 "데이터 보안" 항목에도 같은 내용이 선언돼 있습니다. 이 문서와 스토어 선언이 다르면 스토어 선언이 최신입니다.

사용자의 집중 세션 수·타이머 설정 자체는 광고 SDK 로 전달되지 않습니다.

제3자 제공 및 공유

포모도로는 광고 게재를 위해 Google(AdMob) 을 이용합니다. 그 밖의 제3자에게 사용자의 데이터를 제공·판매하지 않습니다.

권한(Permissions)

포모도로는 Android / iOS 에서 다음 권한 외에는 요청하지 않습니다:

  • 알림 표시 권한 — 25분 집중 / 5분 휴식 사이클 완료 시 로컬 알림을 띄우기 위해 사용. 원격 푸시 서버는 사용하지 않음.

위 권한은 사용자가 운영체제 설정에서 언제든 비활성화할 수 있습니다. 권한을 비활성화해도 타이머 자체의 기본 동작에는 영향이 없습니다.

어린이 개인정보 보호

포모도로는 생산성 도구이며 만 13세 미만 어린이를 대상으로 하지 않습니다. 계정·로그인이 없어 앱이 직접 수집하는 어린이 식별 정보는 없습니다.

보안

기기 내부 저장소는 운영체제의 앱 샌드박싱으로 보호됩니다. 광고 SDK 가 Google 서버와 주고받는 통신은 Google 이 제공하는 보안 연결을 사용합니다.

사용자 권리

포모도로는 서버에 사용자별 데이터를 보관하지 않으므로 별도의 계정 삭제 절차가 없습니다. 앱 자체를 기기에서 삭제함으로써 모든 데이터를 완전히 제거할 수 있습니다.

정책 변경

이 개인정보 처리방침은 앱의 기능 변경이나 법규 변경에 따라 업데이트될 수 있습니다. 변경 사항이 있을 경우 이 페이지에 반영되며, 최종 업데이트 날짜가 갱신됩니다.

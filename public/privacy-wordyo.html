단어요 개인정보 처리방침

최종 업데이트: 2026년 7월 30일

개요

단어요(Wordyo)는 영어 단어를 카드 형태로 학습하는 앱입니다. 학습 데이터의 처리는 사용자 기기 안에서만 이뤄지고 서버로 전송되지 않으며, 개인 식별 정보(이름·이메일·전화번호·로그인 계정 등)는 수집하지 않습니다. 다만 앱에는 Google AdMob 광고 SDK 가 포함돼 있습니다. 광고를 위해 처리되는 정보는 아래 "광고" 항목에 적었습니다.

수집·처리하는 정보

단어요는 다음 정보를 사용자 기기 내부에서만 처리합니다:

  • 학습 진행도 — 어떤 카테고리의 어느 카드까지 봤는지를 기기 로컬 저장소에만 기록합니다.
  • 즐겨찾기·메모 등 사용자 입력 — 사용자가 카드에 직접 표시한 데이터는 기기 로컬에만 저장됩니다.

단어요 앱 자체는 이름·이메일·전화번호·연락처·사진·마이크 접근 권한을 수집하지 않으며, 회원가입·로그인 절차가 없습니다. 광고 SDK 가 처리하는 정보는 아래 "광고" 항목을 참고해 주세요.

데이터 흐름

단어 카드 데이터는 앱 설치 시 함께 포함되어 있으며, 학습 진행도·즐겨찾기·메모를 서버로 올리거나 내려받지 않습니다. 학습 기능 자체는 인터넷 연결 없이도 동작합니다. 다만 광고를 불러오기 위해 광고 SDK 가 Google 서버와 통신합니다.

데이터 저장

학습 진행도, 즐겨찾기, 사용자 입력 등 모든 데이터는 사용자 기기 로컬 저장소(Android: SharedPreferences, iOS: UserDefaults)에만 보관됩니다. 단어요 앱 자체는 사용자별 데이터를 서버에 저장하지 않으며, 어떤 계정에도 동기화되지 않습니다. 앱을 삭제하면 기기 내부의 모든 학습 데이터가 함께 삭제됩니다.

광고

단어요은 Google AdMob 광고 SDK(google_mobile_ads) 를 포함합니다. 광고가 게재될 때 AdMob 은 광고 식별자, 대략적인 위치, 기기 식별자, 앱 이용 상호작용 등을 수집·이용할 수 있으며, 이 처리는 Google 의 정책을 따릅니다. 자세한 내용은 Google 파트너 사이트·앱에서의 데이터 이용 을 확인해 주세요.

Google Play 스토어의 "데이터 보안" 항목에도 같은 내용이 선언돼 있습니다. 이 문서와 스토어 선언이 다르면 스토어 선언이 최신입니다.

사용자의 학습 진행도·즐겨찾기·메모 자체는 광고 SDK 로 전달되지 않습니다.

제3자 제공 및 공유

단어요는 광고 게재를 위해 Google(AdMob) 을 이용합니다. 그 밖의 제3자에게 사용자의 데이터를 제공하거나 판매하지 않습니다.

어린이 개인정보 보호

단어요는 만 13세 미만 어린이를 대상으로 하지 않습니다. 만 13세 미만 이용자의 개인정보를 의도적으로 수집하지 않으며, 어린이임이 확인되는 경우 해당 데이터를 즉시 삭제합니다.

보안

학습 데이터는 기기 밖으로 나가지 않으며, 기기 내부 저장소는 운영체제의 앱 샌드박싱으로 보호됩니다. 광고 SDK 가 Google 서버와 주고받는 통신은 Google 이 제공하는 보안 연결을 사용합니다. 민감한 메모를 기록하는 경우 기기 자체의 잠금 기능을 활성화하는 것을 권장합니다.

사용자 권리

단어요는 서버에 사용자별 데이터를 보관하지 않으므로 별도의 계정 삭제 절차가 없습니다. 앱 자체를 기기에서 삭제함으로써 모든 학습 데이터를 완전히 제거할 수 있습니다.

정책 변경

이 개인정보 처리방침은 앱의 기능 변경에 따라 업데이트될 수 있습니다. 변경 사항이 있을 경우 이 페이지에 반영되며, 최종 업데이트 날짜가 갱신됩니다.

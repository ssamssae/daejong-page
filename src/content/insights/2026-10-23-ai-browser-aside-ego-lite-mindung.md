# 크롬으로도 되는데 AI 브라우저가 필요한 이유? aside·ego lite·컴퓨터 유즈 완벽 비교 정리 — MINDUNG

## 한 줄 요약
발화자는 AI 브라우저 Aside·Ego Lite를 기존 Playwright·컴퓨터 유즈와 작동 방식·토큰 사용·쓰임새로 비교한다. 코딩 에이전트로 여러 웹 작업을 하면 Ego Lite, 브라우저 안에서 직접 AI와 일하면 Aside, 개발 테스트·정해진 자동화는 Playwright, 데스크톱 앱까지 다루면 컴퓨터 유즈를 권한다.

## 픽업
- **Aside는 브라우저에서 AI에게 바로 일을 맡기는 쪽이다.** 브라우저를 열고 「경쟁사 요금제를 조사해 달라」고 하면 AI가 직접 웹사이트를 돌아다니며 작업한다. 기존 Claude·ChatGPT 구독을 연결할 수 있고 Claude Code·Codex 같은 외부 에이전트와도 연동된다. 비밀번호를 AI에게 직접 노출하지 않고 입력하는 볼트 기능도 있다.
- **Ego Lite는 코딩 에이전트를 위한 브라우저에 가깝다.** Ego 브라우저 스킬을 연결하면 평소 쓰는 AI에게 웹 작업을 맡긴다. 특징은 스페이스라는 작업 공간이다. 한 에이전트는 무신사에서 상품 정보를, 다른 에이전트는 공식 쇼핑몰에서 가격을 각자 별도 스페이스에서 모아 같은 탭을 건드리는 충돌을 줄이고, 사용자도 그동안 다른 탭에서 일할 수 있다.
- **병렬·백그라운드 실행 자체는 새 브라우저만의 기능이 아니다.** Playwright도 별도 브라우저 세션을 띄우거나 창 없이 작업할 수 있다. Ego Lite의 차이는 이런 웹 작업 공간을 AI 에이전트와 함께 관리하기 편하게 만든 데 있다.
- **토큰은 AI가 브라우저를 다루는 방식에서 갈린다.** Playwright MCP는 버튼·입력창 같은 요소를 구조화된 정보로 넘기고 AI가 클릭과 확인을 반복하므로, 복잡한 페이지를 여러 번 읽으면 전달 정보와 호출 기록이 늘어난다. 그래서 Microsoft도 토큰을 줄이는 Playwright CLI 방식을 제공한다.
- **Ego Lite는 여러 동작을 자바스크립트 코드로 묶어 실행하고 필요한 결과만 받는다.** 개발사가 공개한 31개 웹 작업 비교에서 Playwright CLI보다 작업 완료율이 높고 완료당 모델 비용이 낮았다. 다만 자체 벤치마크라 모든 웹사이트에서 같은 결과가 나온다는 뜻은 아니고, Aside도 자체 자동화 엔진을 내세우므로 Ego Lite만 토큰을 아낀다고 볼 수는 없다.
- **컴퓨터 유즈는 화면 이미지를 보고 마우스·키보드로 조작한다.** 이미지 처리 비용이 들 수 있지만 웹페이지 구조만으로 다루기 어려운 프로그램도 조작할 수 있다. 토큰 사용량은 연결한 도구 수보다 AI가 주고받는 정보량과 작업 반복 횟수에 달려 있고, 토큰을 조금 아끼는 것보다 원하는 작업을 실패 없이 끝내는지를 함께 봐야 한다.
- **고르는 기준은 지금 Playwright로 하던 일이다.** 버튼·로그인 테스트나 매번 같은 반복 작업이면 Playwright 스크립트·CLI를 그대로 쓴다. Claude Code·Codex로 매번 다른 사이트를 조사하거나 여러 웹 작업을 동시에 맡기면 Ego Lite, 코딩 에이전트 없이 브라우저에서 로그인 관리와 AI 기능을 함께 쓰려면 Aside, 평소 크롬으로 충분하면 크롬 확장 연결, 데스크톱 프로그램까지 다루면 컴퓨터 유즈를 권한다.

- **Playwright CLI** [도구 통신 (MCP · CLI · API)]: Microsoft가 토큰 사용을 줄이려고 제공하는 Playwright 명령줄 방식.

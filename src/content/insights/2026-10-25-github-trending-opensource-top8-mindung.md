## 픽업
- **1위 Cloudflare Security Audit Skill(`cloudflare/security-audit-skill`, 별 4만 5,000개)은 코딩 에이전트를 보안 감사 담당으로 만든다.** 5일 연속 트렌딩에 올랐다. 코드를 분석해 취약점 의심 지점을 찾고, 별도 에이전트가 「정말 공격 가능한 문제인지」 반박하며 다시 검증한다. 결과는 확인된 취약점과 추가 검증이 필요한 문제로 나눠 보고서로 정리한다. Cloudflare가 자체 취약점 탐색 시스템을 발전시킬 때 출발점으로 쓴 스킬이다.
- **2위 NVIDIA OpenShell(`NVIDIA/OpenShell`, 별 2만 개)은 에이전트를 격리된 공간에서 실행한다.** 어제 4위에서 2위로 올랐다. 에이전트가 접근할 파일과 인터넷 주소를 정책으로 제한해, 특정 프로젝트 폴더에만 접근하거나 미리 허용한 서버에만 접속하게 한다. API 키도 에이전트에 직접 노출하지 않고 허용된 요청에만 전달한다. 최근 0.1 버전대 업데이트로 격리 기능과 API가 확장됐다.
- **3위 AWS 에이전트 툴킷(`aws/agent-toolkit-for-aws`, 별 3,200개)은 아마존이 공식 공개한 AI 에이전트 도구 모음이다.** Claude Code·Codex 같은 코딩 에이전트가 AWS를 더 정확하게 쓰도록 돕는다. 앱을 AWS에 배포하려 하면 어떤 서비스를 쓸지부터 서버 설정·비용·보안까지 AWS 공식 지침을 바탕으로 안내하고, MCP를 연결하면 AWS 서비스 연동 작업도 한다. 발화자는 AI가 AWS 설정을 추측하며 코드를 쓰던 방식이 아마존이 직접 준 도구·지침을 참고하는 방식으로 바뀐다고 말한다.
- **4위 Hallmark(`Nutlope/hallmark`, 별 3만 2,000개)와 6위 Impeccable(`pbakaus/impeccable`, 별 8만 6,000개)은 둘 다 「어딘가 비슷비슷한」 AI 웹 디자인을 고치는 스킬이지만 접근이 다르다.** Impeccable은 명령어 24개(polish 전체 다듬기·typeset 글꼴과 글자 크기·animate 화면 움직임)와 AI가 자주 만드는 디자인 문제를 찾는 검사 규칙 62가지로, 새 디자인뿐 아니라 완성된 사이트의 문제도 찾아 고친다. Hallmark는 테마 48가지로 사이트 목적에 맞춰 화면 구조부터 설계하고(쇼핑몰은 상품 구매, 예약 사이트는 예약 과정 중심), 실제 브라우저에서 여러 화면 크기로 테스트해 뻔한 디자인과 모바일 화면 오류를 찾는다. 기존 사이트의 내용·기능은 그대로 두고 디자인만 바꿀 수도 있다.
- **5위 claude-howto(`luongnv89/claude-howto`, 별 4만 5,000개)는 Claude Code 기능을 제대로 쓰게 돕는 무료 학습 자료다.** 발화자는 Claude Code를 설치하고도 채팅으로 코드만 만드는 사람에게 권한다. 10여 개 과정으로 스킬·MCP·서브에이전트부터 특정 작업이 생길 때 명령을 자동 실행하는 훅까지 다루고, 설정 파일과 명령어를 그대로 복사해 실습하며 퀴즈로 배운 내용을 점검한다. 지난 23일 8위에 이어 이날 5위로 다시 올랐다.
- **7위 Microduck(`pollen-robotics/microduck`, 별 1만 1,000개)은 제어 코드와 학습 환경을 모두 공개한 오리 로봇이다.** 최근 젠슨 황의 연설에 등장했고 출시와 동시에 주문이 몰렸다. 키 25cm·무게 800g에 모터 15개로 두 발로 걷고, 넘어지면 스스로 일어나며 물건도 집는다(바퀴를 달면 굴러다닌다). 걷는 법은 가상 환경에서 강화 학습으로 익혀 로봇에 옮겼으므로, 실물 없이도 컴퓨터에서 가상 오리를 움직이고 새 동작을 직접 가르칠 수 있다.
- **8위 Gemini CLI(`google-gemini/gemini-cli`, 별 10만 8,000개)는 구글이 만든 오픈소스 AI 코딩 에이전트다.** 코드 작성·오류 수정은 기본이고, PDF·이미지·손으로 그린 스케치를 참고해 앱을 만든다. MCP를 연결하면 깃허브 이슈 관리와 코드 작업까지 자동화한다.

## 용어
- **에이전트 샌드박스** [하니스 · 패턴]: 에이전트를 격리된 공간에서 돌리고, 접근할 수 있는 파일·인터넷 주소를 정책으로 제한하는 실행 환경. OpenShell은 API 키도 에이전트에 직접 주지 않고 허용된 요청에만 붙여 보낸다.
- **반박 검증 (적대적 검증)** [하니스 · 패턴]: 한 에이전트가 찾은 문제 후보를 다른 에이전트가 「정말 맞는지」 반박하며 다시 확인하는 방식. Security Audit Skill은 이것으로 확인된 취약점과 추가 검증이 필요한 문제를 나눈다.
- **공식 에이전트 툴킷** [지식 · 컨텍스트 자산]: 클라우드 회사가 직접 내놓은 MCP 서버·스킬·지침 묶음. 에이전트가 설정을 추측하지 않고 공식 지침을 근거로 작업하게 한다.
- **AI 슬롭 (AI slop)** [워크플로우 · 문화]: AI가 만든 티가 나는 뻔하고 비슷비슷한 결과물을 이르는 말. Impeccable·Hallmark가 줄이려는 「어딘가 비슷비슷한 AI 디자인」이 여기에 해당한다.
- **디자인 검사 규칙 (디자인 린트)** [하니스 · 패턴]: 결과물에서 AI가 자주 만드는 디자인 문제를 자동으로 찾아내는 규칙 묶음. Impeccable에는 62가지가 들어 있다.
- **강화 학습 (RL)** [기타]: 시행착오와 보상으로 동작을 스스로 익히게 하는 학습 방법. Microduck은 걷는 법을 이 방법으로 익혔다.
- **Sim-to-Real** [기타]: 가상 환경(시뮬레이션)에서 학습한 동작을 실제 로봇에 옮겨 쓰는 방식. 학습 환경이 공개돼 있으면 실물 로봇 없이도 컴퓨터에서 새 동작을 가르쳐 볼 수 있다.

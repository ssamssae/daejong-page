# 앤트로픽 개발자 리디아가 공개한 클로드 코드 최신 사용법 (상위 0.1%) — MINDUNG

## 한 줄 요약
앤트로픽 클로드 코드 팀 리디아 할리가 밝힌 내부 사용법을 정리한 영상. CLAUDE.md 를 줄이고, 자동 모드·거부 규칙·샌드박스로 승인을 클로드에게 넘기고, 훅·CI·새 클로드 리뷰로 결과를 확인하고, 지휘 세션(페이블 5.2)이 작업 세션(오퍼스 5.5)에 일을 나눠 주는 흐름을 다룬다.

## 픽업
- 앤트로픽의 코드 변경은 5월 하루 2,500건에서 9월 3만 건 이상으로 넉 달 만에 12배 넘게 늘었다. 리디아는 평소보다 훨씬 큰 작업 하나를 맡겨 보고, 멈추는 지점을 하나씩 자동화하라고 한다.
- CLAUDE.md 는 확 줄인다. 연초에 권하던 대문자 IMPORTANT·NEVER·느낌표는 지금 모델에겐 강제성이 너무 세서 쓸데없는 작업이나 엉뚱한 방향을 만든다. 코드에 나와 있는 것(기술 스택·파일 위치)은 지우고 코드만 봐서는 모르는 것만 남긴다. 고르기 어려우면 「닥터 프롬프트 오디트」 명령이 필요 없는 지시를 골라 준다.
- 자동 모드에서 승인 창이 자꾸 뜨면 설정에 믿는 저장소·사이트를 평소 말하듯 적어 둔다. 앤트로픽 실험에서 승인 요청 하나를 누가 봐도 위험한 명령으로 바꿔 보냈더니 사람은 14%만 막았고 자동 모드는 89%를 막았다. 그래도 10개 중 1개는 지나간다.
- 절대 하면 안 되는 일은 거부 규칙에 적는다. .env 는 자동 모드가 기본으로 읽고, 한 번 열면 키가 대화 기록에 남는다. 거부 규칙은 클로드가 치는 명령만 보므로 샌드박스도 켠다. 그러면 npm test 안에서 도는 남의 패키지 코드가 .env 를 열거나 낯선 서버로 보내는 것을 운영 체제가 막는다.
- 몇 시간 걸리는 일은 앤트로픽 서버에서 도는 클라우드 세션에 맡긴다. 저장소만 새로 받아 일하니 .env 와 내 컴퓨터의 키가 따라가지 않고, 필요한 키는 따로 넣으면 모델에게 보이지 않게 쓰인다. 코드 올리기·메시지 보내기는 되돌릴 수 없으니 거부 규칙은 똑같이 건다.
- 오류가 있어도 겉으로는 멀쩡히 끝난 것처럼 보이므로 훅으로 검사를 강제한다(파일 수정 때 코드 검사, 끝낼 때 테스트). 훅이 종료 코드 1이면 작업을 못 막고, 2면 실패 내용이 클로드에게 전달돼 다시 고친다. 리뷰는 작성한 클로드가 아니라 처음 보는 클로드가 하고, 문서·문구는 자동 검사만, 일반 기능은 개발자 1명, 위험한 변경은 2명이 본다.
- 세션 관리도 클로드에게 맡긴다(베타 「클로드 코드 프로젝트」). 지휘 세션(페이블 5.2)에 이번 주 할 일을 한꺼번에 주면 일을 나눠 작업용 세션인 스레드(오퍼스 5.5)를 띄우고 테스트 통과까지 확인한다. 맡길 때는 완료 기준을 명확히, 작은 단위로 나눠 각각 테스트할 수 있게, 실제 실행 결과까지 보여 달라고 한다.

## 용어
- **CLAUDE.md** [지식 · 컨텍스트 자산]: 클로드가 일하기 전에 읽는 안내 파일.
- **자동 모드** [하니스 · 패턴]: 승인 창을 사람에게 띄우는 대신 클로드 코드가 명령의 위험을 판정해 진행하거나 막는 방식.
- **거부 규칙** [하니스 · 패턴]: 절대 하면 안 되는 명령·파일 접근을 적어 두는 설정. 자동 모드가 판단하기 전에 먼저 막는다.
- **샌드박스** [하니스 · 패턴]: 거부 규칙을 운영 체제 수준으로 넘겨, 테스트 중에 도는 남의 코드도 막힌 파일과 허락하지 않은 서버에 닿지 못하게 하는 기능.
- **훅** [하니스 · 패턴]: 특정 상황(파일 수정, 작업 종료 등)에 미리 정한 명령을 자동으로 실행하는 기능. 종료 코드 2 는 실패 내용을 클로드에게 돌려준다.
- **클라우드 세션** [하니스 · 패턴]: 내 컴퓨터가 아니라 앤트로픽 서버에서 저장소만 새로 받아 도는 클로드 세션.
- **CI** [워크플로우 · 문화]: 여러 세션이 만든 코드를 합치기 전에 같은 검사를 자동으로 돌리는 절차.
- **클로드 코드 프로젝트** [하니스 · 패턴]: 지휘 세션이 할 일을 나누고 작업용 세션을 띄워 결과를 확인하는 베타 기능.
- **스레드** [하니스 · 패턴]: 클로드 코드 프로젝트에서 지휘 세션이 띄운 작업용 세션.
- **닥터 프롬프트 오디트** [도구 통신 (MCP · CLI · API)]: 지금 쓰는 모델 기준으로 CLAUDE.md 와 스킬을 훑어 더는 필요 없는 지시를 골라 주는 명령(이름은 자막 표기 그대로).

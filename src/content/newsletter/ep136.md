## 이번 이야기

기록실에 가상 작업 사진과 메모를 넣어 글을 생성했습니다. 결과는 자연스럽게 읽혔지만 입력에 없던 작업 방법이 들어갔습니다. 마른 천을 썼다거나 여러 차례 작업했다는 설명입니다. 문장이 매끄러운지 읽는 것만으로는 이런 추가를 놓치기 쉽습니다.

## 직접 겪은 일

생성과 원문 대조를 나누고, 여러 사례에서 입력 사실이 보존되는지 확인하도록 개선했습니다. 최종 검증에서는 실제 생성한 세 사례의 사실 대조가 통과했고, 오류가 있는 두 사례는 거부되는 것을 확인했습니다. 사진 표시, 복사, 저장, 다시 열기도 확인한 뒤 수정본을 실제 서비스에 반영했습니다.

## 배운 점

자동 검사 전체가 통과하던 때에도 실제 글에는 없던 사실이 들어갔습니다. 기능이 작동한다는 결과와 생성한 내용이 정확하다는 결과를 따로 봐야 했습니다. 몇 가지 사례의 개선이 모든 작업 사진에서 같은 품질을 보장하는 것은 아니므로, 결과를 읽고 원본과 대조하는 과정은 여전히 필요합니다.

## 독자에게

사진이나 메모로 글을 만든다면 결과에서 동작을 나타내는 문장을 골라 보세요. 어떤 도구를 썼는지, 몇 번 했는지, 무엇이 해결됐는지가 원본에 있는지 대조하면 됩니다. 문장을 더 자연스럽게 고치기 전에 근거가 없는 설명부터 지우는 순서가 이번 점검에 도움이 됐습니다.

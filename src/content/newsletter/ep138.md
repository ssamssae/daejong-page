## 이번 이야기

문의노트에서 작성한 문의와 답변을 내 기기에 남기는 방식을 만들었습니다. 서버의 데이터베이스에 기록을 보내는 대신 브라우저가 저장을 맡고, 다른 곳에서 만든 초안은 파일이나 붙여넣기로 가져오게 했습니다. 별도 서버 저장 비용 없이 사용할 수 있는 방향입니다.

## 직접 겪은 일

문의를 작성한 뒤 새로고침해도 기록이 남는지 확인했습니다. 백업 파일을 내려받아 빈 저장 공간에 복원했고, 같은 파일을 다시 가져왔을 때 중복이 추가되지 않는지도 확인했습니다. 잘못된 파일을 넣으면 기존 기록이 유지돼야 합니다. 실제 생성 도구가 파일 대신 문장 안에 데이터를 돌려준 경우를 위해 붙여넣기 경로도 추가했습니다.

## 배운 점

저장 장소를 기기로 옮기면 백업과 복원 경로가 더 중요해집니다. 한 화면에서 잘 저장되는 것만 확인해서는 다른 환경으로 옮길 수 있는지 알 수 없습니다. 이번 웹 버전은 공개 화면에서도 저장, 새로고침, 파일 추가를 확인했습니다. 별도로 만든 모바일 앱은 이 날짜 기준 구현과 시뮬레이터 검증 단계였습니다.

## 독자에게

기기에 저장하는 도구를 쓴다면 중요하지 않은 예제 기록으로 백업을 만들어 보세요. 빈 테스트 저장 공간에 가져왔을 때 내용이 복원되는지, 같은 파일을 두 번 넣어도 중복되지 않는지 확인하면 됩니다. 평소 데이터가 있는 공간을 지우지 않고 복원 경로를 시험하는 편이 안전합니다.

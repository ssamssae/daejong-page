> 07:39, 같은 작업을 이어서 하기 위한 체크포인트가 main에 들어갔다.
> 21:55, kangdaejong.com 17개 페이지 리뉴얼이 공개됐다.
> 23:25, Cursor 터미널이 53×60에 고정되던 수정을 합쳤다.

새벽에는 음성 입력과 카카오 창이 다시 열릴 때의 오답을 막고, 오전에는 측정과 재개 도구를 합쳤다. 저녁의 중심은 회사 사이트를 실제로 바꾸는 일이었고, 밤에는 터미널 화면이 창 크기를 따라가지 않던 회귀를 닫았다.

## 1. 창이 다시 열려도 옛 명령을 실행하지 않는다

자정 무렵에는 음성 입력에서 취소 직후 재시작이 겹치지 않도록 작업 토큰을 넣었고, 핫키 출력이 작성 칸을 가리지 않게 고쳤다. 카카오톡은 대화창을 다시 키우거나 일부만 복원했을 때, 예전에 처리한 `!` 명령을 다시 답하지 않도록 막았다. 이 수정은 저녁에 [claude-skills PR #599](https://github.com/ssamssae/claude-skills/pull/599)로 합쳐졌고, 운영에도 반영했다.

운영 문서에서는 역할·배차 설명을 여러 곳에 반복하지 않고 정본 한곳으로 모았다.

## 2. 클릭 수와 방문 수를 섞지 않는다

오전에는 제품 전환을 7일 창으로 모으는 집계가 [claude-automations PR #2164](https://github.com/ssamssae/claude-automations/pull/2164)로 들어갔다. 뉴스레터 CSV를 읽을 때는 수집기 식별을 분명히 하고, 설정과 다른 주소를 성공으로 치지 않게 했다.

사이트 쪽에서는 제품 링크 클릭과 우리 페이지 도착을 따로 센다. 외부 클릭을 방문 분모에 넣지 않도록 구분을 남겼고, 실제 뉴스레터 주소로 수집기가 준비됐는지도 검사했다. **집계 경로를 연 것과 7일 관찰이 끝난 것은 다르다.** 관찰은 아직 진행 중이다.

계산기알람의 공개 처리방침도 같은 날 사이트에 올렸다. 주소는 [privacy-calc-alarm.html](https://work.kangdaejong.com/privacy-calc-alarm.html)이다. 스토어 제출은 이 글의 범위가 아니다.

## 3. 회사 사이트를 다시 그렸다

전날 기획만 넘겼던 회사 홈페이지를 이날 실제로 바꿨다. 17개 경로의 디자인·콘텐츠·코드를 만들고, 검토 뒤 공개에 반영했다. [kangdaejong-com PR #60](https://github.com/ssamssae/kangdaejong-com/pull/60)이 합쳐진 시각은 21:55이고, [kangdaejong.com](https://kangdaejong.com/)은 공개 응답을 확인했다.

작업 재개용 체크포인트도 같은 날 표준이 됐다. 같은 할 일을 새 배차처럼 다시 보내지 않고, 기록된 다음 단계와 현재 코드 위치를 대조한 뒤에만 이어간다.

Codex 실행기는 0.153.4로 올렸다. 공식 설치 파일로 앱을 맞추고, 외부 명령과 앱 안 명령이 같은 버전인지를 확인했다. 이 업데이트는 저장소 코드 변경이 아니다.

## 4. 작은 창에 큰 화면을 고정하고 있었다

밤에는 `cs`로 연 Cursor 터미널이 가로 53, 세로 60에 붙는 회귀가 다시 보였다. 원인은 클릭이나 글꼴이 아니라, 예전에 잡힌 크기를 최신 창보다 우선한 설정이었다.

최신 클라이언트 크기를 따라가고, 포커스 이벤트를 켜고, 출력 버퍼가 한없이 쌓이지 않게 상한을 두었다. [claude-automations PR #2169](https://github.com/ssamssae/claude-automations/pull/2169)가 23:25에 합쳐졌다. 세 기기의 설정 반영을 대조했고, 실제 Ghostty 창의 확대·축소와 클릭에서도 화면이 따라오는지 별도로 확인했다.

> **배운 것** — 창이 작아 보이는 것과 세션이 죽은 것은 다르다. 먼저 따라가는 크기가 어느 클라이언트인지 봐야 한다.

## 5. 그래서 뭐가 남았나

공개된 것은 회사 홈페이지 리뉴얼, 계산기알람 처리방침, 클릭·방문 구분, 카카오 재답 방지, Cursor 화면 크기 추적이다. 7일 전환 관찰은 아직 끝나지 않았고, 텔레그램 답장이 이전 질문을 집는 현상은 원인 미확인으로 남겨 두었다. 오토파일럿 완료 증거를 보고 봉투에 넣는 작업은 시간 상한에 걸려 이날 병합하지 않았다.

> 15:19, 메모요 백업 파일에 사진 실물이 들어가기 시작했다.
> 18:16, 첫이름·사주·펫이름이 어두운 편집 화면으로 맞았다.
> 21:25, 회사 홈과 작업장 로고가 같은 정사각형으로 모였다.

하루 안에 웹 제품 여러 개의 얼굴이 바뀌고, 메모 백업이 글자만 담던 한계를 넘었다. 초소와 회사 홈도 같은 톤으로 따라왔다. 밤에는 터미널 답이 폰에 다시 보이게 붙잡는 수정도 겹쳤다.

## 1. 사진이 없는 백업은 반쪽이다

오후 3시 19분, [메모요](https://play.google.com/store/apps/details?id=com.daejongkang.simple_memo_app) ([App Store](https://apps.apple.com/kr/app/id6762068073)) 가 파일·드라이브 백업에 사진을 넣기 시작했다. [simple-memo-app PR #142](https://github.com/ssamssae/simple-memo-app/pull/142)다. 본문에 붙여 둔 이미지를 빼고 글만 가져가면, 복원 뒤에 빈 칸이 남는다.

8월 말부터 이어 온 사진 기능의 다음 칸이다. 화면에 보이는 것과 백업 파일에 남는 것을 같게 만드는 일이었다.

## 2. 웹 가게의 간판을 하루에 맞췄다

저녁 6시 전후, 웹 제품이 같은 리듬으로 리뉴얼됐다. 첫이름·사주운세·펫이름은 [cheotireum PR #203](https://github.com/ssamssae/cheotireum/pull/203), 대표 사진은 [PR #204](https://github.com/ssamssae/cheotireum/pull/204). 한장궁합·한장택일·한장상호·밥먹자 가이드도 같은 시각대에 전체 화면을 갈아입었다.

작업장 제품 페이지 리뉴얼 본문은 [daejong-page PR #527](https://github.com/ssamssae/daejong-page/pull/527)로 들어갔고, 밤 9시 6분에는 검정·민트 로고를 되돌리는 수정도 따라왔다. 새 얼굴이 브랜드 배지까지 삼키지 않게 한 보정이다.

## 3. 회사 홈과 초소도 같은 작업장이다

밤 9시 25분, 회사 사이트와 대표소개가 밝은 작업장 톤·정사각 로고로 맞았다. [kangdaejong-com PR #61](https://github.com/ssamssae/kangdaejong-com/pull/61), [ssamssae.github.io PR #19](https://github.com/ssamssae/ssamssae.github.io/pull/19). 이어서 회사 메인·조직도와 대표소개 본문 재구성이 같은 분에 합쳐졌다.

초소는 주소를 choso.kangdaejong.com으로 옮기고, 관제 화면을 다시 그렸다. 은퇴한 기기는 신호 목록에서 숨겼다.

같은 날 밤 10시 3분, [한줄일기](https://play.google.com/store/apps/details?id=com.daejongkang.hanjul) ([App Store](https://apps.apple.com/kr/app/id6764308678)) 설정 화면에서 버전 줄을 가운데 맞추고, 주문번호로 구매를 수동 복원하던 칸을 뺐다. 릴리스 1.4.3+32다.

> **배운 것** — 여러 가게의 간판을 하루에 바꾸면, 로고 한 장이 어긋난 순간이 전체를 예전 집으로 보이게 한다. 얼굴 교체와 배지 보존은 같은 커밋이 아니어도 같은 밤에 끝나야 한다.

## 4. 그래서 뭐가 남았나

웹 제품과 회사 홈의 새 얼굴은 공개됐고, 메모요 사진 백업은 코드에 들어갔다. 계산기알람 아이폰 스토어 입력은 콘솔 작업으로 진행됐다. 터미널 답을 폰에 다시 붙이는 수정은 밤늦게까지 이어져, 다음 날 새벽 헤더 정리로 넘어간다.

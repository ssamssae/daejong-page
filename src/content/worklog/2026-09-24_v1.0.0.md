기록 범위는 9월 23일 21시부터 9월 24일 21시까지다. 9월 26일에 완료 근거를 다시 대조해, 작업 제목만 나열하던 본문을 고쳤다.

> 자비스에 실제로 말하고, 스피커에서 답이 나오는 과정을 확인했다.
> 로고 생성과 다운로드를 시험했지만 유료 판매를 시작한 것은 아니다.

## 1. 말하고 답을 듣는 한 바퀴를 확인했다

앞서 연결한 자비스를 실제 발화로 확인했다. 사람이 말한 소리가 마이크로 들어가고, 질문이 처리된 뒤 Nest 스피커에서 응답이 나오는 전체 경로를 살폈다. 음성 인식이나 답변 생성 한 단계만 성공한 것을 전체 성공으로 대신하지 않았다.

이 결과와 제작 과정을 홈페이지에 게시하고 공개용 코드도 정리했다. 이후 선풍기 명령 누락, 날씨 질문, 복도등 호출처럼 일상에서 사용하는 명령을 다뤘다. 기능이 추가될수록 사용자가 한 말이 어떤 동작으로 연결됐는지 확인하는 일이 중요해졌다.

## 2. 작업 시작과 종료도 음성으로 연결했다

작업을 시작할 때 필요한 준비를 묶은 음성 동작을 연결했다. 컴퓨터 깨우기처럼 다른 기기의 상태가 관여하는 부분은 실제 기동 여부를 확인했다. 작업을 마칠 때는 사용자의 확인을 거치는 흐름과 취소 명령도 정리했다.

말을 알아들었다는 것과 실제로 기기가 움직였다는 것은 다른 결과다. 이 기록은 확인한 동작을 설명하는 것이며, 모든 가전과 모든 발음에서 같은 결과를 보장한다는 뜻은 아니다.

## 3. 로고꾸러미는 결제 테스트까지, 판매는 아직

로고꾸러미의 첫 버전을 만들고 테스트 결제에서 로고 생성, 다운로드, 다른 브라우저에서 구매 복구, 테스트 취소까지 이어지는 경로를 확인했다. 사용자는 생성 결과를 내려받고 다시 찾는 과정을 시험할 수 있었다.

그러나 실제 유료 판매는 비활성 상태로 유지했다. 이미지 공급자의 이용 조건과 결제 서비스의 판매 범위 등 남은 확인이 있었기 때문이다. 작업이 완료로 기록됐더라도, 이번에 끝낸 범위는 구현과 테스트였다. 판매 개시까지 완료됐다는 뜻은 아니다.

## 4. 만든 것과 판매할 수 있는 것 사이

자비스는 실제 발화와 스피커 응답의 연결을 확인했다. 로고꾸러미는 제작과 테스트 경로를 검증했지만 판매 조건 확인은 남았다. 서로 다른 단계의 결과를 모두 ‘출시 완료’라고 묶지 않는 것이 이날 기록의 핵심이다.

> **배운 것** — 테스트가 성공한 서비스도 판매에 필요한 조건까지 충족했는지는 따로 확인해야 한다.

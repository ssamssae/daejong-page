기록 범위는 9월 24일 21시부터 9월 25일 21시까지다. 9월 26일에 완료 근거를 다시 대조해, 작업 제목만 나열하던 본문을 고쳤다.

> 사진을 보정하고 파일로 내려받는 기본 기능을 무료로 공개했다.
> 홈페이지에서는 현재 프로젝트와 이전 프로젝트를 나눴다.

## 1. 사진꾸러미는 기본 보정부터 열었다

사진 보정 서비스를 만들면서 기본 이미지 처리와 외부 AI를 이용한 편집, 결제 기능을 함께 검토했다. 모두 같은 단계에 있지는 않았다. 기본 보정은 검증할 수 있었지만, 외부 AI 품질과 실제 결제·메일 연결 등은 추가 확인이 필요했다.

그래서 먼저 [사진꾸러미](https://kangdaejong.com/photo/)의 브라우저 기본 보정을 무료로 공개했다. 공개된 페이지에서 실제 사진 파일과 여러 결과를 묶은 압축 파일이 내려받아지는지 확인했다. 서비스 이름도 사진결에서 사진꾸러미로 바꿨다.

이날 공개한 것은 기본 보정이다. 외부 AI를 이용한 편집이나 유료 상품까지 개시했다고 설명하지 않는다. 관련 코드와 모의 검사가 있어도 실제 공급자·결제 서비스에서 확인해야 하는 일은 남아 있다.

## 2. 지금 만드는 것과 이전에 만든 것을 나눴다

[홈페이지](https://kangdaejong.com/)는 현재 진행하는 프로젝트를 2.0으로, 앞서 만든 앱과 도구를 1.0 보관 목록으로 나눴다. 새 방문자가 지금 제공하는 것과 이전 작업을 구분할 수 있게 하려는 정리다.

컴퓨터와 모바일에서 버전 사이 이동과 주요 링크를 확인했다. 예전에 공유한 전자책 위치로 이동하는 링크도 유지했다. 아직 시작하지 않은 다음 버전은 실제 서비스처럼 눌러 들어가게 만들지 않았다.

## 3. 로고와 링크 미리보기도 맞췄다

회사 로고의 배치와 공통 이미지 관리 방식을 정리하고, 홈페이지 링크를 공유할 때 나타나는 이미지와 설명도 맞췄다. 실제 공개 이미지와 새 공유 미리보기를 확인했다. 다만 이미 보낸 메시지의 미리보기까지 즉시 바뀐다고 보장하지는 않았다. 메시지 서비스가 이전 이미지를 저장해 둘 수 있기 때문이다.

자비스의 음성 입력에는 출처 표시를 별도로 붙이는 작업도 있었다. 말한 본문을 고치지 않으면서, 음성으로 들어온 입력이라는 정보를 구분하는 방식으로 확인했다.

## 4. 이날 공개한 범위

사진꾸러미의 무료 기본 보정과 홈페이지의 프로젝트 구분은 공개 페이지에서 확인했다. 사진꾸러미의 외부 AI·유료 연동, 로고꾸러미의 판매 조건 확인은 남아 있었다. ‘서비스를 만들었다’와 ‘모든 유료 기능을 열었다’를 같은 말로 쓰지 않기로 했다.

> **배운 것** — 먼저 쓸 수 있는 범위를 명확히 공개하고, 아직 제공하지 않는 기능은 설명에서도 구분해야 한다.

## 1. 음성 입력을 시작하고 전달하는 과정

음성 입력에서 사용할 도구와 컴퓨터를 차례로 고르는 흐름을 적용했습니다. 스피커에서 재생한 음성으로 선택과 취소를 검사했고, 별도로 사용자가 실제 연결과 입력이 잘 된다고 확인했습니다. 시작을 맡는 스마트 스피커와 본문을 받아 적는 컴퓨터의 역할을 나눴습니다. 모든 도구와 컴퓨터 조합의 인식률을 측정한 것은 아닙니다.

## 2. 작성한 글에 원본에 없는 설명이 들어가던 문제

기록실에 가상 사진과 메모를 넣어 생성한 글을 대조했습니다. 입력하지 않은 작업 과정이 추가되는 문제가 있어 글 생성과 사실 대조를 나눠 개선했습니다. 최종 실제 사례 세 건과 오류 사례 두 건으로 확인했고, 사진·복사·저장·다시 열기 동작도 검증했습니다. 수정본을 서비스에 적용하면서 기존 계정과 저장 글, 사용량을 보존했습니다.

## 3. 문의 내용을 기록하는 첫 버전

문의 문안을 만들고 업체별 진행 상태와 답변을 기록하는 문의노트의 첫 로컬 버전을 구현했습니다. 저장한 내용을 다시 읽고 서버를 재시작해도 유지되는지 확인했습니다. 이 단계에서는 실제 브라우저 클릭과 클립보드 동작이 미확인이었으며, 외부 문의를 발송하거나 공개 서비스로 배포하지 않았습니다.

## 4. 완료로 묶지 않은 부분

기록실의 직접 사용성 점검은 실제 고객의 평가와 구분했습니다. 생성문 품질은 이번에 다룬 사례의 결과를 기준으로 설명했고, 모든 입력에서 오류가 사라졌다고 확대하지 않았습니다. 음성 입력 역시 사용자의 실제 성공 확인과 합성음 시험을 각각 근거로 남겼습니다.

## 1. 홈페이지의 화면과 정보 정리

홈페이지의 디자인을 개편하고 휴대폰부터 큰 화면까지 글과 메뉴가 보이는지 확인했습니다. 실제 공개 화면에서 주요 링크, 키보드 이동과 화면 동작을 점검했습니다. 이후 요청에 따라 음식 메뉴 추첨 영역을 제거했고, 프로젝트와 서비스 안내가 유지되는지 다시 확인했습니다. 먼저 확인한 기능이라도 최종 공개 상태에서는 제거됐다는 점을 기록합니다.

## 2. 문의노트를 브라우저에 저장하도록

문의 기록을 서버 데이터베이스 대신 브라우저에 저장하는 웹 버전을 만들었습니다. 작성한 내용을 새로고침한 뒤 복원하고, 파일 추가와 붙여넣기로 초안을 가져오는 과정을 확인했습니다. 백업을 빈 저장 공간에 복원했으며 같은 파일의 중복 추가와 잘못된 파일 입력 시 기존 데이터 보존도 검사했습니다. 공개 웹 화면에서 저장과 파일 추가가 작동하는지 확인했습니다.

## 3. 모바일 앱은 구현과 검증까지

휴대폰 내부에 문의 기록을 저장하는 앱도 구현했습니다. 자동 검사와 기기용 빌드를 통과하고, 시뮬레이터에서 파일 백업·가져오기와 재실행 후 복원을 확인했습니다. 이 날짜의 제작 범위에는 고객 휴대폰 설치와 스토어 배포가 포함되지 않았습니다. 웹 공개와 모바일 배포를 하나의 완료로 설명하지 않습니다.

## 4. 남긴 확인 기준

저장 완료 표시는 시작점이었습니다. 다시 열었을 때 내용이 남는지, 다른 빈 공간에서도 백업이 복원되는지까지 확인해야 기록 도구의 사용 흐름을 설명할 수 있었습니다. 이번 과정에서는 기존 공개 데이터와 사용 중인 기기를 보존하고, 검증에 쓴 예제 기록을 정리했습니다.

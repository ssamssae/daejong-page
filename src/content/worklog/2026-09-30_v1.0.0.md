## 1. 시작 화면은 완전히 다시 켜서 확인

계산기알람과 가계부 등을 실제 아이폰에서 종료한 뒤 다시 실행했습니다. 일곱 앱이 정상 홈 화면에 도달했고 관찰 중 충돌은 없었습니다. 계산기알람의 설치 아이콘과 가계부·약먹자·더치페이의 시작 그림을 녹화로 확인했습니다. 이미 떠 있는 앱으로 돌아가는 동작과 처음부터 시작하는 동작을 구분해 살폈습니다.

## 2. 체크인 직후 화면을 떠나도 전송되도록

살아있음에서는 저장 직후 다른 탭으로 이동하면 체크인이 전송되지 않는 결함을 발견했습니다. 화면이 바뀌어도 암호화 전송을 끝내도록 고쳤고, 수정 전 실패와 수정 후 통과를 확인했습니다. 실제 기기와 시뮬레이터 조합에서 양방향 수신을 점검하고, 오프라인 저장 후 앱을 종료했다가 네트워크를 복구한 뒤 상대 기기로 전달되는 과정도 확인했습니다.

## 3. 동기화 구현과 남은 실사용 확인

우리사이는 암호화 동기화와 푸시를 구현하고 기기 조합별 일기 수신, 사진·댓글·하트, 오프라인 복구를 확인했습니다. 아이폰의 위치 관련 초기 등록 문제도 수정했습니다. 테스트 빌드를 올린 결과와 실제 테스트 앱 설치는 구분했습니다. 장시간 백그라운드 위치 동작, 충전기를 뺀 배터리 측정 등은 별도 잔여로 남겼습니다.

## 4. 실패하면 사용자의 선택을 유지

살아있음의 위치 선택이 전송 시도 전에 풀리는 문제도 수정했습니다. 전송하거나 암호화 대기열에 저장하는 데 성공한 뒤에 선택을 해제하고, 실패하거나 취소하면 유지하도록 바꿨습니다. 관련 자동·네이티브 검증과 소스 통합까지 확인했으며, 이 후속 수정의 새 빌드 배포와 상대 기기 실제 수신은 별도로 남겼습니다.

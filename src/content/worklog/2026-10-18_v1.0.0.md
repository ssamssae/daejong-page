## 1. 무엇을 고치려 했나

홈페이지 「만들며 배운 것」에는 판매를 끝낸 전자책 세 권이 판매 종료로 남아 있었다. 배너에서 종료한 제품을 빼자는 말 뒤에, 세 권은 무료 공개로 정했다. AI 사업일지에는 새 글이 필요했는데, 발행 확인은 사이트가 프로그램의 기본 접속 정보를 막아 공개 페이지를 항상 열리지 않은 것으로 표시했다. 어느 컴퓨터에서나 글을 올리게 해 달라는 요청도 있었으나, 당시 발행 권한은 일부 컴퓨터에서 거절됐다. 직접 호출하지 않아도 사용량이 나가는 자동 기능이 켜져 있었고, 맥을 바꾸기 전에 늘 켜 두던 배경 작업을 줄여야 했다. 우분투 화면의 글자는 깨져 보였다. 기본 터미널로 둔 컴퓨터에서는 숨기려던 창이 닫히지 않고 다시 나타났다. 폰에서 작업 강도를 바꾼 뒤 화면을 비우거나 다음 메시지를 보내면 약 60초간 멈추고 처리 중 표시가 두 번 뜨기도 했다.

## 2. 바뀐 것과 확인한 결과

전자책 세 권은 홈의 무료 읽기 링크로 배포됐다. 공개 홈에는 판매 종료 문구가 없었고, PDF 링크 세 곳 모두 문서 형식으로 정상 응답했다. 기존 판매 페이지는 손대지 않았다. 사업일지 두 편도 공개 주소가 정상으로 열리고 제목과 요약이 맞았다. 앞의 글은 자동 확인이 막혀 접속 정보를 지정해 수동으로 비교했다. 뒤의 글은 자막과 다시 대조해 고칠 곳이 없었고, 확인 프로그램을 고친 뒤 공개로 판정됐다. 텔레그램 연결 프로그램은 바뀐 두 가지만 공개 목록에 올렸고, 본체가 그대로인 두 가지는 올리지 않았다. 이미 돌아가던 네 곳의 연결은 새 파일로 켜져 있어 재시작하지 않았다. 자동 기억과 자동 이어 하기, 로컬 예약은 설치 여섯 곳에서 꺼진 값을 다시 읽어 확인했다. 직접 호출, 메신저 연결, 자동 복구, 로그인, 구독, 대화 기록은 남겼고, 답을 생성해 보는 시험은 하지 않았다. 편집기 네 대는 요청한 모델의 상태 표시와 저장값이 같았고, 명령줄 도구는 네 대가 같은 버전이었으며 한 대만 새로 받았다. 도움말 확인은 통과했고 답변 시험은 빠졌다. 켜 둔 세션은 다음 실행 때 새 파일을 쓰도록 그대로 뒀다. 글자가 깨지던 쪽은 터미널을 설치하고 다른 컴퓨터와 같은 기본값으로 저장했다. 다시 뜨던 빈 창은 창 없는 실행으로 다시 등록했고, 그 컴퓨터에서 새 콘솔이 없으며 감시가 동작 중임을 확인했다. 작업 강도 변경의 확인창은 고른 값으로 자동 응답하게 고쳐 반영했고, 자동 시험에서는 1.43초 만에 응답이 나갔다. 한 터미널 화면 아래의 피드백 초안은 설정을 꺼서 보이지 않게 했고, 대기 초안 한 건은 삭제하지 않고 보관했다. 대화 기록 수집은 멈추고 원본은 압축해 보관했다. 농장 보조, 원격 보조, 새벽 점검, 메신저 자동 실행은 설정 파일을 남긴 채 종료했다. 아이폰 연결용 통로와 일일 뉴스레터 점검도 멈췄다. 지금 맥의 설정 서른 개 파일은 스냅샷으로 남겼다. 카드 게임 보조, 할 일 동기화, 감시 두 가지는 끄지 않았다.

## 3. 이번 작업의 의미

확인이 실패로 나오면 글이 없는 상태와, 확인 프로그램의 접속이 막힌 상태를 나누게 됐다. 발행 위치를 넓힌 조치는 특정 발행 명령만 묶어 허용한 것이다. 시험에서는 그 명령만 통과하고, 다른 종류의 배포와 덧붙인 명령은 거절됐다. 자동 기능 세 가지가 꺼진 뒤의 상태는, 부르지 않으면 사용량이 나가지 않고 부르면 기존 대화와 구독을 그대로 쓰는 대기다. 맥에서 한 정리는 이전 전에 남길 작업과 멈출 작업을 파일을 지우지 않고 가른 준비다. 빈 창을 다시 등록한 이유는 숨김 옵션이 새 기본 터미널에서 창을 숨기지 못했기 때문이다. 작업 강도 변경을 고친 이유는 확인 질문이 다음 메시지 앞에서 입력을 붙들기 때문이다. 무료로 바뀐 뒤 독자의 경로는 홈의 파일 링크다.

## 4. 아직 남은 일

글자가 깨지던 컴퓨터는 주황 창을 닫고 검은 아이콘으로 다시 열어야 화면이 바뀌는지 알 수 있다. 그 재오픈은 아직이다. 새 대화가 최대 강도를 포함한 직전 강도를 잇는 코드는 반영됐고 도우미는 최대를 출력했으나, 실제 재시작 적용은 보지 못했다. 강도 변경 수정은 자동 시험과 두 컴퓨터 대조까지이고, 사람이 폰으로 보낸 기록은 없다. 전부 로그아웃하라는 중간 지시는 정정돼 실행되지 않았고, 계정 사이트의 자동 예약과 저장소 자동 리뷰는 확인하지 않았다. 메신저 자동 보조는 앱을 종료한 뒤에도 로그아웃하지 않은 상태다. 초소 손님 주소는 은퇴로 오류 응답이며, 홈 배너와 머리글, 시스템 페이지의 링크 제거는 결정 전이다. 새 맥 이전은 아직이고 블루투스 재연결은 메모만 있다. 오프라인 컴퓨터는 여섯 시간마다 나던 설정 경고에서 빠져 있으며, 새 맥을 연결한 뒤 되돌린다. 검사한 컴퓨터에서는 문제가 없었고, 빠진 컴퓨터는 검사하지 않았다. 넓힌 발행 허용은 격리 시험이며, 그 컴퓨터의 이후 실제 발행 기록은 없다. 리눅스 두 대의 도구 갱신 건, 홈택스 로그인 절차, 운영 알림 수신 변경은 종료 시각이나 제목만 있어 결과 확인으로 보지 않는다. 홈의 무료 전자책 링크 하나를 열어 파일만 받아 보면 된다.

## 1. 무엇을 고치려 했나

새 맥으로 옮긴 뒤 답변 완료 방송과 키 신호음과 승인 표시등이 집 스피커와 전등에 닿지 못했다. 집 안 통신 허가는 기본 도구에만 붙고 따로 서명된 실행에는 붙지 않았다. 허가 목록을 직접 고치면 다른 앱 허가까지 초기화될 수 있어 원본은 그대로 두었다. 복도 표시등은 오후 1시 58분부터 파란 빛이 약하게 남았고, 오래 켜진 작업이 전구에 실패해도 잠금을 쥔 채 30초마다 다시 시도했다. 선택 질문은 화면을 보라는 글 알림으로 도착했다. 메모 앱은 삭제와 복원 안내, 화면을 떠난 뒤의 결과와 되돌리기, 설정 복원 뒤의 메모, 열람과 수정의 구분, 사진 단추 위치에 사용이 막히던 장면이 있었다. 10월 17일부터 21일 글은 홈페이지와 뉴스레터와 네이버에 비어 있었다. 발행 확인 프로그램은 사이트가 기본 신원을 거절해 이미 올린 글도 열리지 않은 것으로 적고 있었다. 서울역 전광판 자료는 10월 19일 제공 거부였다.

## 2. 바뀐 것과 확인한 결과

방송 세 가지는 집 안 통신 허가를 가진 음성 앱이 대신 내도록 바꿨고, 제어만 다시 시작해 서명과 허가는 유지했다. 신호음과 완료 방송이 끝났고, 승인 음성과 표시등은 켜진 뒤 요청이 끝나자 대기로 돌아왔으며 키 선택도 통과했다. 오래 켜진 작업을 끝내고 다시 띄우자 표시등은 대기가 됐고, 복도등은 19시 12분에 꺼진 것이 두 번 읽혔다. 5분을 넘는 실패는 잠금을 넘기도록 바꿨고 자동 시험은 통과했다. 질문 카드는 경고 아이콘의 숨은 문자를 비교에서 뺀 뒤 연결 한 곳을 재시작해 오류 없이 붙였다. 두 윈도우 컴퓨터의 챗봇 알림음은 재부팅 뒤에도 꺼져 있었고 알림음 재생 기록은 없었으며 화면 알림은 남았다. 메모 앱은 안 닫히던 삭제·복원 안내, 화면을 떠난 뒤의 결과와 되돌리기, 설정 복원 뒤 사라지던 메모, 보기만 해도 수정되던 처리, 커서를 가리던 사진 단추를 고쳐 코드에 합쳤다. 자동 분석과 자동 시험은 통과했고 버전은 1.0.20 그대로다. 홈페이지 신원 거절을 고친 뒤 10편과 뉴스레터 5편의 공개를 확인했고 저녁 9시 예약을 다시 켰다. 네이버는 영수증 보안문자에서 두 번 멈춘 뒤 사람이 직접 로그인한 세션으로 18일부터 21일 4건을 올렸고, 18일은 시간 초과 한 번 뒤 성공했다. 17일 글 발행 검사는 공개 상태였다. 서울역 전광판 분쟁조정은 10월 22일 접수 대기이며 본문은 1분에 1회와 파일 대안이 있는 초안과 같았다. 새 맥 점검 14항목은 19시 53분에 모두 참이었고, 계획된 재시작 뒤 비정상 재시작과 패닉은 없었다. 실제 통화 두 건은 전달까지 확인됐다. 수신 감시는 실행 중이었다. 세션 비우기 한 번은 새 세션에 착지했고, 비운 직후 바쁘다고 읽던 판독도 고쳤다. 문자 도구는 본문 대조와 실제 허가 확인으로 고쳤고, 허용 뒤 질문 없이 재실행됐으며 발송은 0건이었다. 파일과 사진은 네 곳 반영 뒤 두 컴퓨터 전송이 성공했고 두 맥은 자격 해석이 됐다. 외장 디스크는 내장 복사와 파일 482,567개가 같고 확장 속성 차이 2건을 본 뒤 지워 사용량 772KiB가 되었고, 내장 미러는 남았다. 단톡방 문안 한 건은 20시 39분 53초에 갔고 가리지 않은 화면에서 노란 말풍선이 확인됐다. 데스크톱 로그인 수정은 공유본에 합쳐졌다.

## 3. 이번 작업의 의미

이 구조는 허가를 우회하지 않고, 집 안 기기에 말하는 주체를 이미 허용된 음성 앱으로 모은 것이다. 독자가 바로 열어 볼 수 있는 변화는 홈페이지와 뉴스레터와 네이버에 올라온 글이다. 전광판 건의 의미는 접수된 다툼까지다. 디스크를 비운 뒤에도 대조된 복사본은 내장에 남는다.

## 4. 아직 남은 일

구글 홈으로 복도등을 한 번 다루는 확인은 소리 복구 때 빠졌고, 전구 접근을 잃은 원인도 확정 전이다. 질문 카드 수정은 재시작한 한 곳에 적용되며 나머지 세 곳은 다음 재시작을 기다리고, 이모지가 든 긴 질문의 실제 카드도 한 번 남아 있다. 메모 앱은 손 위 기기와 실제 드라이브 확인, 스토어 제출이 모두 남아 있다. 10월 20일 뉴스레터는 주소가 두 개이고 메일이 없다. 22일 밤 9시 발행 결과는 확인 전이다. 전광판 조정은 사건번호 없이 접수 대기만 확인됐다. 문자 허가는 특정 설치 경로에 묶여 있고 사람 수신 확인은 없다. 수신 감시는 켜졌으나 시험 파일 투입은 없었고, 폰 잠금을 푼 주체는 확인되지 않았다. 세션 판독 수정은 매번 새로 읽는 쪽에 바로 적용되고 상주 연결은 재시작 때 반영된다. 통화 품질 일곱 가지와 짧은 영상 다섯 편은 확인된 결과가 없다.
